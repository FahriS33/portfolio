# 🚀 Modern Portfolyo Sitesi

Bu repo, GitHub Pages altyapısını kullanarak geliştirilmiş kişisel portfolyo sitemi içermektedir. Modern ve responsive tasarımıyla profesyonel çalışmalarımı sergilemek için tasarlandı.

## ✨ Özellikler

- 📱 Tamamen responsive tasarım
- 🎨 Modern ve minimalist arayüz
- 🔗 Smooth scroll navigasyon
- 📊 Beceri göstergeleri
- 📝 İletişim formu
- 🖼️ Proje kartları
- 🌙 Profesyonel renk paleti

## 🔧 Teknolojiler

Bu projede aşağıdaki teknolojiler kullanılmıştır:

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript (Vanilla)
- Font Awesome (ikonlar için)

## 🖥️ Demo

Bu siteyi [[fahris33.github.io](https://fahris33.github.io/portfolio) adresinden ziyaret edebilirsiniz.

## 📄 Bölümler

Site aşağıdaki ana bölümlerden oluşmaktadır:

1. **Ana Sayfa / Karşılama** - Kişisel tanıtım ve hızlı erişim linkleri
2. **Hakkımda** - Kişisel bilgiler ve yetenekler
3. **Projeler** - Tamamlanmış çalışmaların portföyü
4. **İletişim** - İletişim bilgileri ve mesaj formu

## 🚀 Kurulum ve Kullanım

Bu projeyi kendi portfolyonuz olarak kullanmak için:

1. Bu repoyu forklayın veya indirin
2. `index.html` dosyasını açın ve içeriği kendi bilgilerinizle güncelleyin:
   - İsim, unvan ve tanıtım metinlerini değiştirin
   - Projelerinizi ve becerilerinizi güncelleyin
   - İletişim bilgilerinizi düzenleyin
3. Değişiklikleri commit edin ve GitHub'a push edin
4. GitHub Pages'i etkinleştirin

## 📝 Kişiselleştirme

Site temel CSS değişkenleri kullanılarak kolayca kişiselleştirilebilir:

```css
:root {
    --primary-color: #2563eb;
    --dark-color: #1e293b;
    --light-color: #f8fafc;
    --accent-color: #3b82f6;
    --text-color: #334155;
}
```

Bu değerleri değiştirerek sitenin renklerini kolayca değiştirebilirsiniz
```

## 📱 Responsive Tasarım

Site aşağıdaki ekran boyutları için optimize edilmiştir:

- 📱 Mobil: 320px - 768px
- 💻 Tablet: 768px - 992px
- 🖥️ Masaüstü: 992px ve üzeri

## 🔧 İletişim Formu

İletişim formunu çalışır hale getirmek için:

1. Bir form işleme servisi kullanabilirsiniz (FormSubmit, Formspree, vb.)
2. HTML'deki form etiketinin action özelliğini kendi endpoint'iniz ile değiştirin:

```html
<form class="contact-form" action="YOUR_FORM_ENDPOINT" method="POST">
```
